# Vision Guardian

A smart tool to analyze terms & conditions and detect risk levels.

## Features
- Detects LOW, MEDIUM, HIGH risk
- Clean UI with dark theme
- Real-time text analysis

## Output Preview

![App Output](assets/output.png)

## Example Cases

- "This app is safe and secure" → LOW ✅  
- "We may share your data with third party" → MEDIUM ⚠️  
- "Your data has been leaked" → HIGH 🚨
